## 优先级与限速

| 优先级 | 数据源                         | 说明                                                             |
| ------ | ------------------------------ | ---------------------------------------------------------------- |
| 1      | 腾讯财经、交易所/官方机构      | 不封 IP 或风险极低；仍应控制频率                                 |
| 2      | 新浪、巨潮、同花顺、华尔街见闻 | 风险低；部分接口有连续性/反爬限制                                |
| 3      | mootdx、baostock               | TCP 客户端；mootdx 行情命令已失效，baostock 不支持北交所         |
| 4      | 东财                           | 仅用于其独有数据；所有请求必须经 `em_get()` 串行限流，间隔 ≥1 秒 |
| 5      | iwencai                        | 唯一需要 API Key 的来源；仅用于 NL 语义搜索                      |

东财风控阈值（社区实测）：每秒 >5 次、单 IP 并发 ≥10、每分钟 ≥200 次、5 分钟 ≥300 次会显著提高封禁风险。被封表现为 403 / 429 / 连接重置 / 空数据；403 不要重试，降频或换网络。

## 通用约定

- **缺失不等于 0**：接口返回空串、`-`、`null` 时记为缺失；是否可交易、是否满足条件应按策略规则处理。
- **结构变化要报错**：字段数、表头、分页总数、日期不符时应显式失败，不把错误页或空响应当成「没有数据」。
- **日期要核对**：官方数据经常只提供最近交易日/当前快照；历史回填、非交易日、未发布要区分。
- **单位要确认**：成交量常见「手」与「股」两种；金额常见「元」「万元」「亿元」；收益率/权重常见小数与百分数两种。
- **编码**：腾讯行情/逐笔、部分新浪页面是 GBK；东财、巨潮、多数 JSON 接口是 UTF-8。
- **交易制度**：A 股 T+1、100 股整手；北交所代码 4/8/92 段，部分接口不支持北交所。

## 已失效或不推荐

- 网易财经、和讯、凤凰行情：站点/接口已下线。
- 雪球免登录深度数据：需要 token。
- 腾讯资金流 `ff_*`：已失效。
- 财联社旧 `nodeapi`：2026-05 下线；新 `v1/roll/get_roll_list` 可用。
- mootdx 的 `bars` / `quotes` / `transaction`：2026-09 起返回 0 行；财务与 F10 仍可用。
- 大商所官网日行情：有 JS 反爬（HTTP 412），未接入；用新浪 `futures_kline` / `futures_realtime`。
- 同花顺深股通分钟流向：2024-08 后披露收紧，`sgt` 仅参考；权威北向用港交所日统计。
- 东财北向净买额：2024-08 后上游断供，返回 NaN/0；不要用于信号。
