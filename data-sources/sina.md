## 1. 实时行情快照 —— `hq.sinajs.cn`

```
GET https://hq.sinajs.cn/list=<代码1>,<代码2>,…        # 可一次请求多只，逗号分隔
```

- **代码前缀必需**：`sh600519` / `sz000001` / `bj920982`（北交所实测可用）；指数写 `sh000001`、`sz399006`；ETF 如 `sh510300`。
- **响应是 GBK 文本**，每行形如 `var hq_str_sh600519="字段1,字段2,…";`（约 34 个字段）。
- ⚠️ **必须带 `Referer`**（实测无 Referer 直接 **HTTP 403 Forbidden**）：

```js
// 最小可用示例（Node 18+）
const GBK = new TextDecoder('gbk')
async function snapshot(codes) {
  const r = await fetch('https://hq.sinajs.cn/list=' + codes.join(','), {
    headers: { Referer: 'https://finance.sina.com.cn/', 'User-Agent': 'Mozilla/5.0' },
  })
  if (!r.ok) throw new Error('HTTP ' + r.status)
  const text = GBK.decode(Buffer.from(await r.arrayBuffer()))
  const out = {}
  for (const line of text.trim().split('\n')) {
    const m = /var hq_str_(\w+)="(.*)";?/.exec(line)
    if (m) out[m[1]] = m[2].split(',')
  }
  return out
}
const q = await snapshot(['sh600519', 'sh000001', 'sh510300'])
```

## 2. K 线 —— `CN_MarketDataService.getKLineData`

```
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData
    ?symbol=sh600519&scale=5&ma=no&datalen=1023
```

- `symbol` 带市场前缀；`scale` = 周期（分钟数）；`datalen` = 取最近 N 根。响应为 **UTF-8 JSON 数组**，**不强制 Referer**（实测无 Referer 也 200）。
- **周期实测表**：

| scale        | 周期          | `amount` 字段    | datalen 上限（实测）                                     |
| ------------ | ------------- | ---------------- | -------------------------------------------------------- |
| 5            | 5 分钟        | ✅ 有            | **1023**（`2000` → `null`）                              |
| 15 / 30 / 60 | 15/30/60 分钟 | ✅ 有（60 实测） | 同 5 分钟量级                                            |
| 240          | **日线**      | ❌ **无**        | 约 1500–2000（`1500` 可用、`2000` → `null`，未精确二分） |
| 1200         | 周线          | ❌ 无            | 同上                                                     |

- **字段**：
  - 分钟线：`{day:'2026-10-14 14:50:00', open, high, low, close, volume(股), amount(元)}`——所有值是**字符串**。
  - 日/周线：`{day:'2026-10-12', open, high, low, close, volume(股)}`——**没有 amount**。
- **时间戳是「结束时刻」**（与东财一致）：`09:35` 那根覆盖 09:30–09:35；日线 `day` 为当日日期。
- **不复权**：跨除权日直接比较价格会错；需要复权用 §4 的因子序列。
- 实测：`datalen=3&scale=5` → 3 根，首根 `{"day":"2026-10-14 14:50:00","open":"1285.470",…,"amount":"82760251.2266"}`；`scale=240` → `{"day":"2026-10-12","open":"1262.950",…,"volume":"3155604"}`。

> 本项目 `short_pick/data/fetch_min5.js` 即用此端点（`scale=5`，带 `Referer`）；其金额侧与官方日线的 ≤2% 口径差见 README「数据口径」。

### ⚠️ `turnover` 的 ×100 坑（本项目已踩并修正）

**两票独立验证**（用本地流通股本缓存反推）：

| 标的     | 快照成交量    | 流通股本      | 算得换手率 | API `turnover` | `turnover ÷ 100` |
| -------- | ------------- | ------------- | ---------- | -------------- | ---------------- |
| sh600519 | 2,377,273 股  | 1,250,081,374 | 0.1902%    | 19.0169        | **0.1902%** ✅   |
| sz300476 | 18,908,253 股 | 865,195,904   | 2.1854%    | 218.543        | **2.1854%** ✅   |

自检公式：`turnover ÷ 100 == 成交量(股) ÷ 流通股本 × 100`（分毫不差）。
**`dragon_pick/data/lib.js` 已于 2026-10-14 修正**（入库前 ÷100）——修正前 `score.js` 的「5 日均换手 ∈ 10%~25%」会对**真实换手 0.10%~0.25%** 的冷门股错误加分、对正常活跃股（真实换手 2% 读到 200）错误扣分。

## 4. 复权因子 —— `qfq.js` / `hfq.js`

```
GET https://finance.sina.com.cn/realstock/company/sh600519/qfq.js     # 前复权因子
GET https://finance.sina.com.cn/realstock/company/sh600519/hfq.js     # 后复权因子
```

- 响应形如 `var sh600519qfq={"total":33,"data":[{"d":"2026-06-26","f":"1.0000000000000000"},…]}`，
  **末尾挂着 `/* base64 */` 注释块**——不要用 `$` 锚定正则，从第一个 `{` 起 `JSON.parse` 到最后一个 `}`。
- **字段**：`d` = 生效日（除权日）；`f` = 因子（**字符串**，精度 16 位）。
- **运算方向相反，传错不报错只会把价格放大/缩小数倍**：
  - **前复权**：`前复权价 = 不复权价 ÷ f(d)`（取**不晚于该 K 线日**的最近一条因子）
  - **后复权**：`后复权价 = 不复权价 × f(d)`
- **实测（sh600519，33 条，按日期倒序）**：qfq 最新 `2026-06-26 → 1.0`（前复权以最新为基准）；最老 `1900-01-01 → 8.8825`（**哨兵**，覆盖开市前的任何日期）；hfq 方向正好相反（最新 8.8825、1900 哨兵 1.0）。
- **自检**（不满足说明响应被截断或代码写错）：
  1. qfq 序列**最新一条恒为 1.0**；hfq **最早（或哨兵）恒为 1.0**；
  2. 同一日期 `qfq(d) × hfq(d) ≡ 常数`（茅台 = 8.8825126710204000），但两者**不是倒数**。
- **限制**：北交所无因子文件（`bj920982` → 404）。
- 与本项目关系：`tdx_data/tdx_parsed` 是不复权价，回测的除权处理走「日涨幅链/价格水平链」（`signal.js`）；
  新浪因子可作为**第三方交叉核对**（`chain 比值` 应与 `prevClose 链` 一致）。

## 10. 通用注意事项

1. **编码**：`hq.sinajs.cn`、研报页是 **GBK**；`getKLineData` / 财报 / zhibo 是 UTF-8。混用会得到乱码或解析异常。
2. **Referer**：`hq.sinajs.cn` 与期权接口**必需**（缺 → 403）；K 线/财报/zhibo 实测不强制。
3. **限流**：新浪整体宽松，但**研报列表接口连续请求会返回假空页**（§6）；批量任务仍建议 ≥200ms 间隔。
4. **数值都是字符串**：JSON 里的价格/量额一律先 `Number()`；比较用数值勿用字符串。
5. **数据时点**：快照 `[31]` 为最近更新时间；K 线为结束时刻口径；财务按期更新（`publish_date` 字段）。
6. **零鉴权≠零风险**：字段是新浪内部实现，可能无预警变更——本项目对分钟线的用法已由 `selftest V8` 每批校验（对账日线）。
