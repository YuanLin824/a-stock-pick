# 通达信数据源参考

通达信有两条完全不同的取数路径：

1. **官网盘后包**（HTTP）：某个交易日沪深北全市场日线，含成交额，适合收盘后全市场截面。
2. **mootdx**（TCP 7709）：财务快照与 F10 仍可用；K 线/盘口/逐笔自 2026-09 起返回空。

> 本文件整理自 `a-stock-data` V3.10.2，实测日期见各节。

## 1. 官网盘后包

```text
GET https://www.tdx.com.cn/products/data/data/g4day/{YYYYMMDD}.zip
```

- 每个交易日一个 zip，约 2.7MB；收盘后数小时发布。
- 非交易日或尚未发布返回 404；历史包实测 2022-01-04、2023-01-03 可取，2021-01-04 已 404。
- 2022-05-06 起包含北交所文件；之前只有沪深。

### 1.1 文件结构

zip 内每个市场一对文件：

```text
sh{YYMMDD}.cod   # 代码表，150 字节/条
sh{YYMMDD}.md1   # 行情块，512 字节/块
sz{YYMMDD}.cod / .md1
bj{YYMMDD}.cod / .md1   # 2022-05-06 起
```

`.cod` 每条 150 字节：前 6 字节代码（ASCII）、偏移 32 的 2 字节为行情块序号、偏移 40 的 32 字节为 GBK 名称。
`.md1` 每块 512 字节：

| 偏移 | 类型    | 字段         |
| ---- | ------- | ------------ |
| 4    | float64 | 昨收         |
| 12   | float64 | 开           |
| 20   | float64 | 高           |
| 28   | float64 | 低           |
| 36   | float64 | 收           |
| 56   | uint64  | 成交量（股） |
| 72   | float64 | 成交额（元） |

- 代码表条数必须等于行情块数；代码重复、序号重复、长度不是整块、非有限数值、收盘价 ≤0 的板块指数，都要显式处理。
- 逐市场核对最少有价记录数，防止某个市场静默缺失。
- 个股 `volume` 单位是股、`amount` 单位是元；指数等特殊代码的 `volume` 是通达信原值。

### 1.2 校验

- 代码必须是 6 位 ASCII 数字；名称必须是 GBK 且非空。
- 每个市场有价记录数低于实测下限（沪 ~10000、深 ~3000、京 ~50）时视为文件残缺。
- 与腾讯收盘价对拍通过后再入库。

## 2. mootdx（TCP 7709）

```python
from mootdx.quotes import Quotes

client = Quotes.factory(market='std', server=('119.97.185.59', 7709))
```

> mootdx 0.11.x 的 `BESTIP.HQ` 空串 bug 会让裸 `factory()` 抛 `ValueError`。建议显式传服务器，并用真实取数验活；完整 `tdx_client()` 见 skill 本体。

### 2.1 仍然可用

- `finance(symbol='688017')`：季报快照，37 个字段（EPS、ROE、净利润、主营收入、股本等）。
- `F10(symbol='688017', name='最新提示')`：公司文本摘要；2026-09 起服务端只剩「最新提示」一类，内含最新提示/互动问答/最新公告/最新报道/最新异动/大宗交易/融资融券/风险提示约 1.2 万字。
- 除权除息等财务类命令仍正常。

### 2.2 已失效

2026-09-20 逐台实测内置 10 台服务器：TCP 均可达，`finance`/`xdxr` 正常，但：

- `bars()`：K 线返回 0 行；
- `quotes()`：五档盘口返回 0 行；
- `transaction()`：逐笔返回 0 行。

替代：

| 原能力      | 替代                                                      |
| ----------- | --------------------------------------------------------- |
| K 线        | 腾讯 [tencent.md](./tencent.md)；全市场日线用本文件盘后包 |
| 实时价/五档 | 腾讯实时行情；交易所官方五档                              |
| 当日逐笔    | 腾讯逐笔（只有最近交易日）                                |
| 财务/F10    | mootdx `check='finance'`，仍可用                          |

## 3. 使用建议

- 收盘后全市场筛选优先用官网盘后包：一次请求拿到沪深北全市场日线，含成交额。
- 盘后包不是「实时」数据；当天包通常收盘后数小时才发布。
- 财务/F10 用 mootdx 时，验活要针对 `finance`，不要用 K 线命令验活（会误判全部服务器不可用）。
- 海外网络访问 TCP 7709 通常全部超时；mootdx 需要国内网络或代理。
- 解析二进制包时所有偏移/长度都要校验，不能把截断文件当完整数据。
