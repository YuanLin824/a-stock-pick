# 腾讯行情数据源 API 参考（实测版）

> 面向本仓库的接口清单与**逐字段释义**。端点于 **2026-10-23** 用 Node 24 实测；脚本实现见 [`scripts/overnight/tencent.mjs`](../scripts/overnight/tencent.mjs)。
> 当前「一夜持股」策略只使用本文件中的腾讯行情/分时/K 线/逐笔，以及深交所交易日历，不调用东财。

## 0. 能力总览

| #   | 数据           | 端点                                        | 用途                                                   |
| --- | -------------- | ------------------------------------------- | ------------------------------------------------------ |
| 1   | 实时行情快照   | `https://qt.gtimg.cn/q=...`                 | 现价、昨收、涨幅、量比、换手率、总市值、涨跌停价、VWAP |
| 2   | 当日分时       | `.../appstock/app/minute/query?code=...`    | 逐分钟价格、累计成交量/额，计算 VWAP                   |
| 3   | 5 日分时       | `.../appstock/app/day/query?code=...`       | 回放与验证（`probe`）                                  |
| 4   | 日线（前复权） | `.../appstock/app/fqkline/get?param=...`    | MA5/10/20、近三日量能                                  |
| 5   | 1 分钟 K 线    | `.../appstock/app/kline/mkline?param=...`   | 14:00–14:30 高低点、分时高低价                         |
| 6   | 当日逐笔       | `https://stock.gtimg.cn/data/index.php?...` | 最终候选的 VWAP 复核                                   |

分时与 K 线有三个入口可轮换，单入口失败后冷却 120 秒再试：

- `https://web.ifzq.gtimg.cn`
- `https://proxy.finance.qq.com/ifzqgtimg`
- `https://ifzq.gtimg.cn`

所有请求带浏览器 `User-Agent`；行情、分时/K 线、逐笔另带 `Referer: https://gu.qq.com/`。

## 1. 实时行情 —— `qt.gtimg.cn`

```text
GET https://qt.gtimg.cn/q=sh600519,sz000001
```

- 代码带市场前缀：`sh600519` / `sz000001`；每批最多 50 只，批间 120ms。
- 响应为 **GBK** 文本，每行形如 `v_sh600519="字段0~字段1~…";`，字段用 `~` 分隔，有效记录至少 52 个字段。
- 空字符串或 `-` 一律转 `null`，**不要当 0**。

| 索引 | 字段       | 说明                               |
| ---- | ---------- | ---------------------------------- |
| 1    | 名称       | GBK 解码                           |
| 3    | 现价       |                                    |
| 4    | 昨收       |                                    |
| 5    | 今开       |                                    |
| 30   | 行情时间   | `YYYYMMDDHHMMSS`                   |
| 31   | 涨跌额     |                                    |
| 32   | 涨跌幅     | %                                  |
| 33   | 最高       |                                    |
| 34   | 最低       |                                    |
| 35   | 复合字段   | 以 `/` 分隔，第 3 段为成交额（元） |
| 36   | 成交量     | 手                                 |
| 37   | 成交额     | 万元                               |
| 38   | 换手率     | %                                  |
| 39   | 市盈率 TTM |                                    |
| 43   | 振幅       | %                                  |
| 44   | 流通市值   | 亿元                               |
| 45   | 总市值     | 亿元                               |
| 46   | 市净率     |                                    |
| 47   | 涨停价     |                                    |
| 48   | 跌停价     |                                    |
| 49   | 量比       |                                    |
| 51   | 当日均价   | VWAP，与分时累计额/量同源          |

常用派生判断：

- **停牌/僵尸报价**：成交额为 0，且现价等于昨收。
- **涨停**：现价 ≥ 涨停价；**一字板**：最高 = 最低且现价触及涨停/跌停。

## 2. 当日分时 —— `minute/query`

```text
GET https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600519
```

响应结构：

```json
{
  "code": 0,
  "data": {
    "sh600519": {
      "data": {
        "date": "20261023",
        "data": ["0930 10.00 1234 1234000", "0931 10.01 1567 1568000"]
      }
    }
  }
}
```

每行格式为 `HHMM 价格 累计成交量(手) 累计成交额(元)`，盘中实时更新。VWAP 直接由累计列计算：

```text
VWAP(t) = 累计成交额(t) ÷ (累计成交量(t) × 100)
```

这是与行情字段 51 同源的精确值，不是近似值。计算正常交易时段时过滤 `0930 ≤ HHMM ≤ 1500`；15:06–15:30 为盘后定价，需排除。

## 3. 5 日分时 —— `day/query`

```text
GET https://web.ifzq.gtimg.cn/appstock/app/day/query?code=sh600519
```

`data.<code>.data` 是以 `"0"`~`"4"` 为键的对象，每个值包含 `date` 和 `data` 数组，行格式与当日分时相同。仅用于回放/验证。

## 4. 日线与 1 分钟 K 线

```text
GET https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,60,qfq
GET https://web.ifzq.gtimg.cn/appstock/app/kline/mkline?param=sh600519,m1,,320
```

- 日线响应取 `data.<code>.qfqday`（无前复权数据时回退 `day`）；分钟线取 `data.<code>.m1`。
- 每行顺序为 **`[日期, 开, 收, 高, 低, 量]`**——注意是「开、收、高、低」，不是常见 OHLC。
- 日线日期为 `YYYY-MM-DD`；分钟线为 `YYYYMMDDHHMM`。分钟线单次最多 320 根。
- K 线**没有成交额字段**；成交量单位为手。
- 返回 `msg === "param error"` 表示参数错误，换入口重试没有意义。
- 三个入口都不可用时明确报错，不把空响应当 0。

## 5. 当日逐笔 —— `stock.gtimg.cn`

```text
GET https://stock.gtimg.cn/data/index.php?appn=detail&action=data&c=sh600519&p=0
```

- 响应为 **GBK**：`v_detail_data_sh600519=[0,"序号/时间/价格/涨跌/成交量/成交额/方向|…"];`
- 每页通常 70 笔，页码从 0 开始；翻到空页结束，页间间隔 100ms。
- `成交量` 单位为手，`成交额` 单位为元，方向为 `B`/`S`/`M`。
- 仅提供最近交易日；指数与北交所不支持。
- `VWAP = Σ成交额 ÷ (Σ成交量 × 100)`；计算正常时段时过滤 `time ≤ 15:00:59`。

## 6. 限速与容错

- 行情每批 50 只，批间 120ms；逐笔页间 100ms。
- 分时/K 线三入口轮换，失败入口冷却 120 秒。
- 请求超时：行情/逐笔默认 10 秒，分时/K 线 20 秒；行情/逐笔遇到网络错误、429、5xx 最多重试 3 次，403 不重试；分时/K 线靠三入口轮换。
- 解析失败直接抛错；字段缺失记为 `null`，不静默按 0 处理。

## 7. 实测校验

- `qt[51]` 与分时最后一根累计 VWAP 在 0.01 内一致。
- 逐笔 VWAP 与分时 VWAP 偏差约 0.007%，小于策略使用的 0.2% 容差。
- 可用以下命令复核：

```bash
npm run overnight:probe -- sh600519
npm run overnight:probe -- sh600519 --ticks
```
